## 🎯 身強身弱分析

### 核心概念：身強身弱

| 術語 | 白話解釋 | 場論詮釋 |
|------|----------|----------|
| **身強** | 日主能量充沛，自我意識強，承受力強 | 核心場能量飽滿，需要輸出消耗 |
| **身弱** | 日主能量不足，需要外部支持 | 核心場能量不足，需要補充滋養 |
| **中和** | 能量平衡，不強不弱 | 核心場穩定，彈性空間大 |

### 判定項目解釋

| 術語 | 白話解釋 | 代表面向 | 分數意義 |
|------|----------|----------|----------|
| **月令** | 出生月份對日主的支持程度 | 「季節環境」—— 你出生在什麼環境中 | 得令（當旺）+30，不得令 0 或負 |
| **通根** | 日主在地支中有根基 | 「根基穩固」—— 你的能量有沒有根 | 越多根 → 越穩固 → 分數越高 |
| **印星** | 生我的五行（如土生金） | 「資源支持」—— 有沒有人滋養你 | 印星多 → 支持多 → 分數高 |
| **比劫** | 同類五行（如金對金） | 「同類幫助」—— 有沒有同伴 | 比劫多 → 同類多 → 分數高 |
| **洩耗** | 消耗日主能量的五行 | 「能量消耗」—— 輸出或被剋 | 洩耗多 → 負分 |

## 🌟 用神/喜神/忌神

| 術語 | 白話解釋 | 代表面向 | 實際應用 |
|------|----------|----------|----------|
| **用神** | 命局最需要的五行 | 「核心藥方」—— 你最缺什麼 | 取名、擇日、方位選擇的首選 |
| **喜神** | 輔助用神的五行 | 「輔助藥方」—— 幫助用神發揮 | 次選，強化用神效果 |
| **忌神** | 對命局有害的五行 | 「要避開的」—— 會加重問題 | 避免在名字、日期中出現 |
| **閒神** | 對命局影響不大 | 「中性元素」—— 無功無過 | 可用可不用 |

### 你的案例解讀

```
用神：水    → 你需要「流動」—— 學習、溝通、輸出
喜神：木    → 輔助「成長」—— 創新、擴張、發展
忌神：土    → 避免「僵化」—— 保守、過度保護、固守
```

## 📊 身強的建議方向

| 建議 | 白話解釋 | 場論詮釋 |
|------|----------|----------|
| **適合輸出** | 多表達、多創作、多分享 | 能量需要出口，輸出可以平衡 |
| **適合創業** | 有足夠能量承受創業壓力 | 核心場強，可以扛住波動 |
| **適合表現** | 可以站在台前、領導、展示 | 有足夠能量輻射影響他人 |
| **適合花錢投資** | 財為我剋，身強可以駕馭財 | 能量夠強，可以控制資源 |

### 對比：身弱的建議方向

| 建議 | 白話解釋 |
|------|----------|
| 適合團隊合作 | 借助他人能量 |
| 適合穩定職業 | 減少能量波動 |
| 適合學習充電 | 補充核心能量 |
| 適合保守理財 | 不適合大量消耗資源 |
