## 📞 開場（5 分鐘）

### 不要說
```
❌「我來幫你看命盤」
❌「你的八字是...」
❌「讓我算一下你的運勢」
```

### 要說
```
✅「你最近卡在哪裡？」
✅「是關係？決策？事業？」
✅「什麼讓你想來做這個分析？」
```

### 開場話術

**版本 A：直接詢問**
```
「在開始之前，我想先了解：
 你現在最大的決策壓力是什麼？」
```

**版本 B：定位說明**
```
「先說明一下我的服務——
 我不告訴你未來。
 我幫你看結構。

 你願意先分享一下，
 是什麼讓你想來做這個分析？」
```

**版本 C：問題導向**
```
「很多人來找我，
 不是想知道會不會成功，
 而是想知道自己卡在哪裡。

 你是哪一種？」
```

## 🔍 中段：展示模型（15-20 分鐘）

### 核心動作
```
畫五行流動圖給對方看。
讓他看到：「原來我是這樣運作的。」
```

### 步驟 1：解釋日主

**話術**
```
「你的日主是 [X][五行]。
 
 這不是好壞，這是結構。
 
 [五行] 的人，傾向於 [特質]。
 你的能量場是 [場名]。」
```

**範例（庚金）**
```
「你的日主是庚金。
 
 金的人，傾向於結構、規則、判準。
 你的能量場是『收斂規則場』。
 
 這意味著你天生對標準敏感，
 喜歡事情有框架、有邏輯。」
```

### 步驟 2：畫流動圖

**動作**
```
在紙上或螢幕上畫出：

     [剋我]
        ↓
[生我] → 【日主】→ [我生] → [財]
```

**話術**
```
「我畫給你看。

 這是你的能量流動路徑。
 
 [日主] 是你的核心。
 [我生] 是你的輸出方向。
 [生我] 是你的能量來源。
 [剋我] 是你的壓力來源。

 你的用神是 [用神]，
 意思是你需要這個元素來平衡。」
```

### 步驟 3：點出阻力

**話術**
```
「現在我來看你卡在哪裡。

 你的 [忌神] 有點多。
 這代表 [解釋]。

 當 [忌神] 過強的時候，
 你的流動會被阻塞。
 
 這可能就是你現在感覺卡住的原因。」
```

**範例（土為忌神）**
```
「你的土有點多。
 土代表保護、穩定、但也代表僵化。

 當土過強的時候，
 你會傾向守住現有結構，
 但這反而阻礙了流動。

 你需要的是讓水流動起來——
 輸出、表達、學習新東西。」
```

### 步驟 4：連結對方的問題

**話術**
```
「你剛才說你卡在 [問題]。

 從結構來看，
 這很可能跟 [阻力] 有關。

 不是運氣不好，
 是結構上需要調整。」
```

## 💡 關鍵轉折點

### 讓客戶產生「啊哈」時刻

**目標**
```
讓對方說出：
「原來我是這樣運作的。」
「難怪我會這樣。」
「這解釋了很多事。」
```

**技巧**
```
1. 先描述結構
2. 再連結他的實際經驗
3. 讓他自己對號入座
```

**話術**
```
「[結構描述]...
 
 你有沒有發現，
 你在 [某情境] 的時候特別 [反應]？
 
 這就是這個結構在運作。」
```

## 🎯 收尾：轉顧問服務（10 分鐘）

### 過渡話術

**版本 A：自然延伸**
```
「今天我們看到了結構。
 但結構不是看一次就結束。

 如果你想要：
 • 持續調整
 • 在重大決策時有人陪跑
 • 把阻力真的轉化掉

 我們可以談談後續怎麼合作。」
```

**版本 B：問題導向**
```
「現在你知道阻力在哪了。
 問題是：你打算怎麼處理？

 如果你想要有人陪你走這段路，
 我有一個三個月的顧問服務。」
```

**版本 C：價值框架**
```
「我做的不是一次性的命盤解讀。
 我做的是結構優化顧問。

 這意味著：
 • 三個月追蹤調整
 • 重大決策時可以諮詢
 • 幫你把阻力一個一個解掉

 有興趣了解嗎？」
```

### 介紹服務

**話術**
```
「我的顧問服務是這樣的：

 【L3 顧問版】

 • 完整的結構分析報告
 • 五行互動圖
 • 三個月追蹤調整
 • 重大決策時可以諮詢我
 • 如果有重要關係，可以做雙盤匹配

 費用是 NT$ 28,000。

 這不是算命費用，
 這是三個月的結構優化顧問費用。」
```

### 處理猶豫

**如果對方說「讓我考慮一下」**
```
「當然，這是你的決定。

 不過我想問你：
 你現在卡住的問題，
 如果三個月後還是卡住，
 你會怎麼處理？

 我的服務是幫你在這三個月內，
 把阻力識別出來、處理掉。
 
 這個價值，你自己評估。」
```

**如果對方問「有沒有便宜的」**
```
「有。L1 是 NT$ 2,800，純報告。
 但那只是讓你『知道』結構。
 
 L3 是讓你『改變』結構。
 
 這是兩件不同的事。
 你想要哪一種？」
```

## 🚫 紅線：絕對不做的事

```
1. 不回答「會不會成功」
   → 改說「我幫你看結構，決定是你做的」

2. 不做吉凶判斷
   → 改說「這不是好壞，是結構傾向」

3. 不承諾結果
   → 改說「我幫你識別阻力，調整是你做的」

4. 不做情緒安撫
   → 改說「我理解你的感受，但我們專注在結構」

5. 不賣開運商品
   → 只賣顧問服務
```

## 📋 銷售流程總結

```
1. 開場（5 分鐘）
   • 問：你卡在哪裡？
   • 說：我不告訴你未來，我幫你看結構

2. 中段（15-20 分鐘）
   • 解釋日主
   • 畫流動圖
   • 點出阻力
   • 連結對方問題
   → 創造「啊哈」時刻

3. 收尾（10 分鐘）
   • 過渡：結構不是看一次就結束
   • 介紹顧問服務
   • 處理猶豫
   • 成交或留後續

4. 後續
   • 24 小時內發送報告摘要
   • 3 天後跟進
   • 不追逐，保持專業
```
