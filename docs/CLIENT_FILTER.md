# 北斗命數｜高端客戶篩選標準

> 不讓低適配客戶進場，不讓品牌語氣被市場拉低

## 🎯 核心原則

```
你不是解決「焦慮」。
你是優化「結構」。

所以你要篩選的，不是迷信型客戶，而是：
願意承擔決策責任的人。
```

---

## 🔍 三層篩選系統

### 第一層：心態條件（必要條件）

**符合以下 3 項以上才接：**

| 條件 | 說明 |
|------|------|
| ✅ 問「該怎麼走」 | 不問「會不會成功」 |
| ✅ 願意調整自己 | 不要求「改運」 |
| ✅ 接受結構解釋 | 不要吉凶斷語 |
| ✅ 有實際決策壓力 | 事業/關係/資產 |

**直接不接的信號：**

```
「我會不會發財？」
「她是不是正緣？」
「哪一年一定會好？」
「能不能化解？」
「有沒有劫數？」
```

---

### 第二層：經濟與決策層級

**適合的客戶類型：**

| 類型 | 原因 |
|------|------|
| ✅ 創業者 | 有實際決策壓力 |
| ✅ 中高階主管 | 需要結構思維 |
| ✅ 專業顧問 | 理解結構價值 |
| ✅ 事業轉型者 | 需要方向分析 |
| ✅ 投資決策者 | 理性評估需求 |

**不適合的客戶類型：**

| 類型 | 原因 |
|------|------|
| ❌ 學生純探索 | 無實際決策壓力 |
| ❌ 測試準不準 | 心態不對 |
| ❌ 尋求情緒安慰 | 我們不做安撫 |
| ❌ 迷信依賴型 | 會拉低品牌 |
| ❌ 討價還價型 | 不認可價值 |

---

### 第三層：能量匹配

**你（顧問）的特質：**
- 結構型
- 理性型
- 語氣克制

**適配客戶：**
- ✅ 思維型人格
- ✅ 願意對話
- ✅ 不情緒化
- ✅ 能接受不同觀點

**不適配客戶：**
- ❌ 強依附型
- ❌ 情緒化
- ❌ 需要安撫

> 若對方是強依附型或情緒型，你會耗能。

---

## 📋 預約篩選問卷

在預約頁加入 3 個問題，自然篩掉 40% 不適配客戶：

### 問題 1
```
你目前最大的決策是什麼？

（開放題，觀察是否有實際決策壓力）
```

**理想回答範例：**
- 「考慮是否創業」
- 「公司轉型方向」
- 「是否結束現有合作關係」

**警示回答範例：**
- 「想知道今年運勢」
- 「好奇自己的命」
- 「朋友推薦來測一下」

---

### 問題 2
```
你希望改變的是結果，還是結構？

○ 結果（我想知道會不會成功）
○ 結構（我想知道自己卡在哪裡）
```

**選「結果」→ 不適配**
**選「結構」→ 可能適配**

---

### 問題 3
```
若分析結論與你預期不同，你是否願意調整？

○ 願意，我來就是想看清楚
○ 不確定，要看情況
○ 不願意，我已經有答案了
```

**選「願意」→ 適配**
**選「不確定」→ 謹慎**
**選「不願意」→ 不適配**

---

## 📊 篩選評分表

| 維度 | 高分（適配） | 低分（不適配） |
|------|-------------|---------------|
| 決策壓力 | 有實際決策 | 純好奇 |
| 心態 | 問怎麼走 | 問會不會 |
| 調整意願 | 願意改變 | 要改運 |
| 經濟能力 | 能負擔 L2+ | 只願意 L1 |
| 溝通風格 | 理性對話 | 情緒化 |

**評分規則：**
- 5 項全高分 → 優先接
- 4 項高分 → 可接
- 3 項高分 → 謹慎
- 2 項以下 → 不接

## 🚫 拒絕話術

當客戶不適配時，委婉拒絕：

```
「感謝你的信任。
 
 我的服務是結構分析，不是吉凶預測。
 如果你想知道『會不會成功』，
 可能傳統命理服務更適合你。
 
 如果你想知道『自己卡在哪裡』，
 歡迎之後再聯繫。」
```

## 🎯 內測階段目標

```
內測目標：10 位高質量客戶
不是 100 位低單價

追求三件事：
1. 客戶回饋質量
2. 是否真的改變決策
3. 是否願意二次付費
```

## 💡 關鍵判斷

```
如果你讓低適配客戶進來：
→ 被拉向命理市場
→ 被要求吉凶判斷
→ 品牌降級

如果你嚴格篩選：
→ 客戶少
→ 單價高
→ 品牌穩

你適合後者。
```
