# 北斗命數｜品牌語氣統一指南

> 場論決策顧問，不是命理師

## 🎯 核心定位

```
你不是解決「焦慮」。
你是優化「結構」。

你真正賣的不是命數。
是：「理解自己」的框架。
```

## ✅ 品牌核心句型

固定使用的標籤句：

```
「這不是吉凶，是結構。」

「問題不在命，在流動。」

「你不是被限制，是阻力未解。」

「我不告訴你未來，我幫你看結構。」

「命盤不是結果。命盤是結構。
 結構決定阻力，人決定方向。」
```

## 🎨 視覺語氣一致性

### 避免
- ❌ 八卦圖濫用
- ❌ 玄學符號堆疊
- ❌ 太多紅金色
- ❌ 神秘感營造

### 建議
- ✅ 深藍 / 灰 / 白
- ✅ 線條圖、流動圖
- ✅ 結構圖感
- ✅ 專業顧問風格

### 色彩規範
```
主色：#1E3A5F（深藍）
輔色：#4A90A4（冷灰藍）
強調：#E8B85B（暖金，少量）
背景：#F5F5F5（淺灰）
文字：#333333（深灰）
```

## 📝 文案範例

### ❌ 錯誤示範
```
「庚金日主，命帶傷官，
 今年流年沖太歲，小心破財！」
```

### ✅ 正確示範
```
「庚金日主，結構傾向：規則型人格。
 傷官格配置，輸出場強，
 建議今年多創造流動，避免能量阻塞。」
```

## 🔊 對話語氣

### 客戶問：「我會不會成功？」

❌ 錯誤回應：
```
「你命中有財，但要等到45歲後...」
```

✅ 正確回應：
```
「成功是結果，我們先看結構。
 你的能量配置在哪裡有阻力？
 解決阻力，結果自然改變。」
```

---

### 客戶問：「她是不是正緣？」

❌ 錯誤回應：
```
「看夫妻宮，你們前世有緣...」
```

✅ 正確回應：
```
「我不判斷緣分，我看關係結構。
 你們的能量怎麼流動？
 誰付出多？誰依賴多？
 平衡了，關係自然穩定。」
```

## 📌 品牌紅線

絕對不做的事：

1. **不承諾具體結果**（發財、結婚、成功）
2. **不做吉凶判斷**（好壞、該不該）
3. **不用恐嚇行銷**（不改會怎樣）
4. **不賣開運商品**
5. **不做情緒安撫**（只做結構分析）
