## 📖 簡介

**北斗命數**是一套完整的命理分析 SaaS 系統，整合八字、紫微斗數、梅花易數、擇日、合婚等傳統命理工具，以現代科技重新詮釋，提供**機率性參考**而非命定式裁決。

### 核心理念

```
古法是根，場論是枝，用戶是花
```

## ✨ 功能特色

### 命理分析

| 模組 | 功能 | 確定度 |
|------|------|:------:|
| 🔮 八字分析 | 四柱八字、大運流年、用神喜忌 | ★★★★★ |
| ⭐ 紫微斗數 | 命盤排盤、十二宮位、星曜分析 | ★★★★★ |
| 🌸 梅花易數 | 先天起卦、體用分析、占卜問事 | ★★★★☆ |
| 📅 擇日系統 | 嫁娶、動土、開市、搬家吉日 | ★★★★☆ |
| 💑 合婚配對 | 八字合婚、親子配對、合作分析 | ★★★☆☆ |

### SaaS 功能

- ✅ 用戶註冊/登入（JWT 認證）
- ✅ 點數系統（購買/消費/記錄）
- ✅ 報告生成（PDF 下載）
- ✅ 支付整合（綠界/藍新）
- ✅ 數據持久化（SQLite）

## 🚀 快速開始

### 環境要求

- Python 3.11+
- pip

### 安裝步驟

```bash
# 1. 安裝依賴
pip install -r requirements.txt

# 2. 配置環境變數
cp .env.example .env
# 編輯 .env 修改配置

# 3. 啟動服務
python app.py
# 或
./start.sh
```

### 訪問服務

- 前端界面：http://localhost:8000
- API 文檔：http://localhost:8000/docs
- 健康檢查：http://localhost:8000/api/status

## 📚 API 文檔

### 認證 API

| 端點 | 方法 | 說明 |
|------|:----:|------|
| `/api/auth/register` | POST | 用戶註冊 |
| `/api/auth/login` | POST | 用戶登入 |
| `/api/auth/me` | GET | 當前用戶 |

### 命理 API

| 端點 | 方法 | 說明 |
|------|:----:|------|
| `/api/bazi/analyze` | POST | 八字分析 |
| `/api/ziwei/chart` | POST | 紫微排盤 |
| `/api/meihua/divine` | POST | 梅花起卦 |
| `/api/date/select` | POST | 擇日選擇 |
| `/api/match` | POST | 合婚分析 |

### 支付 API

| 端點 | 方法 | 說明 |
|------|:----:|------|
| `/api/payment/plans` | GET | 方案列表 |
| `/api/payment/create` | POST | 建立付款 |

## 🐳 部署指南

### Docker 部署

```bash
docker-compose up -d
```

### 環境變數

| 變數 | 說明 | 預設值 |
|------|------|--------|
| `JWT_SECRET` | JWT 密鑰（必改） | - |
| `DB_PATH` | 數據庫路徑 | `./beidou_unified.db` |
| `ECPAY_SANDBOX` | 綠界測試模式 | `true` |
